# 运行环境配置：

```bash
conda create -n Agent_Project python=3.13

conda activate Agent_Project

pip install -r requirement.txt
```





## requirement.txt文件如下：

```
# 基础（milvus_lite 依赖 pkg_resources，需 setuptools<82）
setuptools>=69.0.0,<82

# 多智能体框架
agentscope==1.0.16

# LLM 调用
requests==2.32.3

# RAG 与向量库（pymilvus[milvus_lite] 用于本地 .db 连接）
pymilvus[milvus_lite]==2.6.9
sentence-transformers==5.2.3

# CLI 界面
rich==13.9.4

# 网络搜索（DDGS）
ddgs==9.10.0

```

1. **基础的兼容层：**`setuptools`
   - 这是 Python 中非常基础的打包和安装工具，很多第三方库需要依赖这个工具。
2. **Agent框架：**`agentscope`
   - 项目中的==多智能体框架==；
     - 负责**agent抽象**；
     - 多agent**协作**；
     - **消息传递**；
     - **工具调用**；
     - **会话/任务编排**
   - 单智能体也可以使用，锁死版本是因为这种框架的版本往往更新很快。
3. **调用大模型API：**`requests`
   - 这是很经典的HTTP请求库，==向网页或API发送请求。==
   - 当然后续有需要也可以再安装openai。
4. **RAG/向量检索：**`pymilvus[milvus_lite]`、`sentence-transformers`
   - `pymilvus[milvus_lite]==2.6.9`是**Milvus向量数据库**的Python客户端
     - `pymilvus[milvus_lite]`能够在安装`pymilvus`的同时，将`milvus_lite`相关依赖一起装上；
     - `milvus_lite`可以不部署完整的 Milvus 服务，就直接在本地使用一个轻量级版本；
       - 本地通过`.db`文件方式运行
   - `sentence-transformers`是一个常用的文本向量化库
5. **命令行美化输出：**`rich`
   - 用来美化终端输出的库，因为存在命令行交互界面
6. **联网搜索：**`ddgs`
   - 用于DuckDuckGo Search的搜索库，让程序可以联网做网页搜索。
